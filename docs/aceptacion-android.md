# Lista de aceptación en Android (Task 12)

**Fecha:** ______________
**Modelo del teléfono:** ______________
**Versión de Chrome:** ______________

| Punto | Qué hacer | Resultado esperado | Resultado |
| --- | --- | --- | --- |
| 1 | Instalar desde `https://j-aravena.github.io/flora/` siguiendo el README. | La aplicación queda instalada y se abre desde su propio ícono. | |
| 2 | Observar el aviso de la primera carga. | Aparece "Datos cargados: 425 especies". | |
| 3 | Revisar el cajón de aplicaciones del teléfono. | Aparece el ícono "Flora" con su propio ícono, no el genérico de Chrome. | |
| 4 | Activar el modo avión, cerrar la aplicación por completo y volver a abrirla. Recorrer lista, ficha y estudio. | Las tres pantallas cargan y funcionan sin conexión. | |
| 5 | Desde una ficha, agregar una foto con la cámara. | La foto se agrega en menos de 5 segundos y queda con la orientación correcta. | |
| 6 | Exportar un respaldo real desde Ajustes. | El proceso termina sin que el teléfono se quede sin memoria; el archivo pesa alrededor de 65 MB. Guardarlo en Archivos o en Drive. | |
| 7 | Importar el respaldo del punto 6 en modo fusionar. | La importación termina sin errores y conserva los datos existentes junto con los del respaldo. | |
| 8 | Importar el mismo respaldo en modo reemplazar. | La importación termina sin errores y reemplaza los datos existentes por los del respaldo. | |
| 9 | En la lista, aplicar un filtro por color de flor y luego uno por pétalos. | Cada filtro reduce la lista a las especies que corresponden. | |
| 10 | Abrir `chrome://settings/content/all`, buscar el sitio de la aplicación y revisar el espacio usado. | El uso de almacenamiento está entre 100 y 150 MB. | |
| 11 | Subir `FLORA_VERSION` en `version.js`, publicar el cambio y volver a abrir la aplicación. | El aviso de actualización aparece en la apertura siguiente al cambio. | |
